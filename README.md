# Kaveen Herath - UI/UX + Front-End Portfolio

A single-page portfolio designed around UI/UX and front-end work, with a darker tech/editorial direction and an electric cyan + violet palette.

## Included
- Responsive one-page portfolio
- Interactive project filters
- Clickable case-study modal for each project
- Scroll reveal animations
- Custom cursor interaction on desktop
- Responsive mobile layout
- Altrium screenshots included in `assets/`

## Before publishing
Open `index.html` and replace:
- `your-email@example.com` with your email address
- Any project links/placeholders you want to change
- Project copy as your work list grows

You can deploy the folder directly with GitHub Pages, Netlify, Vercel, or any static-hosting service.
